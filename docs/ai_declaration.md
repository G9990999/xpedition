# Декларация использования ИИ-инструментов

## Используемые инструменты

В процессе разработки данного решения использовались следующие ИИ-инструменты:

| Инструмент | Назначение |
|---|---|
| Claude (Anthropic) | Помощь в разработке кода, архитектурных решений и документации |

## Область применения

- Генерация шаблонов кода для инференса и предобработки данных
- Разработка структуры проекта и документации
- Анализ требований Технического регламента

## Ограничения

Все сгенерированные ИИ-инструментами фрагменты кода прошли ревью и были адаптированы
под требования задачи командой участников. ИИ использовался как вспомогательный инструмент,
окончательные архитектурные и методологические решения принимались людьми.

## Соответствие правилам

Использование ИИ-инструментов соответствует правилам соревнования KOZ-2 (Xpedition DS).
Обучение модели выполнялось исключительно на предоставленных организаторами данных и
открытых датасетах с совместимыми лицензиями (CC-BY, CC-BY 4.0).
